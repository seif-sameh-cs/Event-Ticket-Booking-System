# 🎟️ Event Ticket Booking System

A comprehensive database management application built to streamline the process of booking event tickets, managing attendees, and generating administrative insights. This project was developed as a practical implementation for the Technology of IS course.

## ✨ Key Features

* **Relational Database Architecture:** Well-structured relational tables designed to ensure data integrity and eliminate redundancy.
* **Interactive User Forms:** Easy-to-use graphical interfaces powered by embedded macros for seamless data entry, ticket processing, and navigation.
* **Dynamic Queries:** Automated data retrieval for filtering events, checking real-time ticket availability, and tracking customer bookings.
* **Executive Reports:** Professionally formatted, print-ready reports designed for management and decision-making overviews.

## 🛠️ Tech Stack

* **Database & UI:** Microsoft Access (`.accdb`)

## 🚀 How to Run

1. Clone this repository to your local machine:

```bash
git clone https://github.com/seif-sameh-cs/Event-Ticket-Booking-System.git
```

2. Ensure you have **Microsoft Access** installed on your Windows environment.

3. Open the `.accdb` file.

4. If prompted by a security warning, click **"Enable Content"** to allow macros and forms to function properly.
